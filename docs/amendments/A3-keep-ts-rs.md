**CONFLICT（措辞/条件需对齐 RFC）**：原默认“保留 ts-rs，待 schema 驱动生成器替换 7 个手写 Types.* 后再删”。RFC 已裁定 ts-rs 退役，且必须与 D8 生成链**同次原子切换**、不得双轨。因此本修订只确认“切换前现状保留”，不是新决定。“7 个手写 Types.* 文件”无法核实：#200 :30 写“6 套手写镜像”，b90f054f 实际可数见 §3。

## 1. RFC 依据
- #200 §0.5 `docs/aisdk-architecture-alignment.md:91`："第一部分 §6.5 的 descriptor + manifest 生成链是唯一生成来源,ts-rs 与 `scripts/gen_*` 退役(第二部分"ts-rs 可继续"的建议不采纳)"；:1358 "ts-rs 和原脚本生成链全部退役"；:2686 同上（删除线裁定）
- RFC-0042 `rfc/0042-v4-type-boundaries.md:18`："descriptor / manifest / codegen 是唯一生成链"；:224 "原 `gen_ts_types.py`、ts-rs 导出及其他被替代脚本在同次原子切换中退役，不能“暂时双轨”留下不同 wire"；§7.2（:204 起）覆盖 Node/TS、Python、Go、Java、Kotlin、Swift、Dart 及 C 共八种接口，"不能手写字段映射"
- 历史：`rfc/0001-multilang-bindings.md:299` 当初选择自动生成以防手写漂移。

## 2. AI SDK 交叉核验
- 不适用：AI SDK 为单一 TS 源，无跨语言生成器；仅 RFC-0042 :222 要求 manifest 记录固定 SDK 基线。无上游 file:line 可引。

## 3. b90f054f 现状
- `Cargo.toml:102` `ts-rs = { version = "12", … }`；`aimux-core/Cargo.toml:19`
- 派生示例：`aimux-core/src/tool.rs:121-123`（`derive(… TS)`, `#[ts(export)]`）
- 生成：`bindings/node/src/types.ts:1-3`（"Generated by scripts/gen_ts_types.py"）
- 手写镜像（已核实存在）：`bindings/swift/Sources/Aimux/Types.swift`、`bindings/kotlin/src/main/kotlin/ai/arcships/aimux/Types.kt`、`bindings/java/src/main/java/ai/arcships/aimux/Types.java`、`bindings/go/types.go`、`bindings/flutter/lib/types.dart`（`types.g.dart` 为生成物），Python 字段映射在 `bindings/python/python/aimux/wrapper.py`。合计 5 个 Types 文件 + Python，与 #200 :30 的“6 套”相符，不是 7。

## 4. Fork 决定与验收
- 决定：D8 切换前保留 ts-rs 与 `gen_ts_types.py` 原状，不新增 ts-rs 依赖面；不并行引入第二个生成器。
- **退役条件（全部满足，同一次提交原子完成）**：
  1. aimux-codegen/manifest 产出八种接口的 DTO/codec（RFC-0042 §7.2），含 Node TS；
  2. 上述手写字段映射文件被生成物替换（只留加载/资源/线程/facade）；
  3. D8 `--check` 在 CI 通过（缺失/过期/多余皆失败，:224）；
  4. 同次删除 `ts-rs`（Cargo.toml:102、aimux-core/Cargo.toml:19）、全部 `derive(TS)`/`#[ts(...)]`、`scripts/gen_ts_types.py`。
- 验收：切换后 `rg -n "ts-rs|ts_rs|#\[ts\(" --glob '!target'` 零命中；在此之前任何 PR 不得出现两套 TS 生成产物。
